## Running Locally

### Prerequisites

Make sure you have:

* [Node.js](https://nodejs.org/) installed
* Git installed

### 1. Clone the repository

```bash
git clone https://github.com/gvaa404/gva-site.git
cd gva-site
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` or `.env.local` file when required by your local setup.

The repository provides `.env.example` as a reference.

Example:

```env
PORT=3000
```

The current project configuration uses port `3000` by default.

### 4. Start the development server

```bash
npm run dev
```

The project uses an Express-based Node.js server for development.

Open:

```text
http://localhost:3000
```
