02 / SYSTEM PROJECT

ROCK

A local Flask-based remote-control dashboard that lets another device control a Windows laptop over the same network. ROCK combines browser-based controls with Windows automation to create a practical laptop companion.

View GitHub Repository ↗ ← All Projects

02 / WHAT IT DOES

A laptop, controlled from another device.

01 / REMOTE CONTROL

Desktop Remote

Control the laptop mouse and keyboard, send text, use shortcuts and view temporary desktop screenshots.

02 / MEDIA

Media Control

Control VLC and browser-based media playback with dedicated remote actions.

03 / BROWSER

Brave Control

Navigate Brave, manage tabs, search or open URLs, control scrolling and use common media shortcuts.

04 / UTILITIES

System Tools

Access clipboard transfer, notes, laptop status, brightness, volume and a restricted application launcher.

03 / TECH STACK

Built with.

Python Flask PyAutoGUI PyGetWindow yt-dlp Pyperclip psutil HTML CSS JavaScript Windows Automation Git & GitHub

04 / SECURITY

Built with safety in mind.

The public repository is structured to avoid committing personal Windows paths and secrets. Authentication uses environment variables, API-changing requests use CSRF protection, file access is restricted to the RockShare directory, and application launching uses a fixed allow-list instead of arbitrary commands.

05 / LEARNING

Why I built it.

ROCK is a practical project for exploring Python automation, Flask APIs, browser interfaces, Windows desktop control, authentication and secure local-network application design.
